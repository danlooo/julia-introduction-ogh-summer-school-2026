# Introduction to Julia

Materials for OpenGeoHub Earth Observation Summer School 2026 in Istanbul, Turkey.

Access slides at [https://danlooo.github.io/julia-introduction-ogh-summer-school-2026](https://danlooo.github.io/julia-introduction-ogh-summer-school-2026)

## Abstract

Julia is an emerging programming language in data science and other fields, promising both fast execution like other compiled languages and interactivity similarly to scripting languages. This introduction outlines the capabilities of this programming language and gives a demo on its basic syntax and applications.
